# RSG_HP — 公式ホームページ（reverstargo.com）の保管用コピー

このフォルダは **公式ホームページ reverstargo.com のHTMLの控え** です。
ゲーム本体（play.reverstargo.com＝リポジトリのルート）とは別物です。

## 大事なこと

**ここを更新しても reverstargo.com は変わりません。**
reverstargo.com は GitHub ではなく **WADAX のレンタルサーバー**で動いています。
公開するには、ここのファイルをダウンロードして、WADAX の管理画面から
アップロードしてください。

- ここ（GitHub）＝ 編集と履歴の保管場所
- WADAX ＝ 実際に公開される場所（reverstargo.com）
- デスクトップの `RSG_HP` ＝ 手元の作業用コピー

2026-08-14 時点で、この3か所の中身は一致している。

## 更新のやり方（2026-08-14 夢吉さんと確認）

1. Claude がこのフォルダを書き換えて push する
2. 同じファイルをチャットに ZIP で渡す
3. 夢吉さんがデスクトップの `RSG_HP` を上書きする
4. そこから WADAX にアップロードする

**夢吉さんは GitHub を操作しない。** ここは Claude 側の編集場所と履歴。
渡す ZIP は、フォルダ名もファイル名も必ず英数字だけにすること
（日本語名だと Windows で文字化けする）。中身は日本語で構わない。

### ⚠ 編集の前に、必ず WADAX から今のファイルを取ってくること

**この控えは本番より古いことがある。** 夢吉さんが WADAX 側だけを更新される
場合があるため、ここを起点に編集して上書きすると、その間の変更が消える。

2026-09-06 に実際に起きかけた：控えは 8/18 で止まっていたが、本番は 8/20 に
研究レポートの節（index.html に44行）・全ページのナビ項目・FAQ 1問が
追加されていた。ファイルサイズを見比べて気づいたので事なきを得た。

**手順**：ファイルマネージャで httpdocs の HTML を丸ごとダウンロード →
この控えに反映 → その上で編集する。サイズ比較（本番のほうが大きければ怪しい）
が簡単な検知方法。

### 改行コードに注意

**ファイルごとにまちまちなので、決め打ちしないこと。**
2026-09-06 時点の本番は次のとおり：

| ファイル | 改行 |
|---|---|
| 日本語版 6ページ（index/features/guide/rules/ranks/faq） | CRLF |
| `privacy.html`（日英とも） | LF |
| `en/index.html` | **CRLF** |
| `en/` のその他5ページ | LF |

`en/index.html` だけ CRLF なのは、以前の記述（英語版は LF）と食い違う。
本番側が変わることがあるので、**各ファイルの実際の形をその都度読み取って、
書き戻すときに同じ形へ戻す**のが正しい。
Python の `io.open(p,'w')` は CRLF を LF に潰すので、バイナリで読み書きする。

## 検索避けについて

この控えは play.reverstargo.com/RSG_HP/ としても配信されてしまうため、
本家 reverstargo.com と検索結果で食い合わないよう、リポジトリ直下の
`robots.txt` で `/RSG_HP/` を巡回対象から外しています。

**ファイルの中身には手を加えていません。**
ここから落としたHTMLは、そのまま WADAX に上げて構いません。
