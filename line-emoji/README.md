## 申請手順（LINE Creators Market）

1. https://creator.line.me/ja/ にLINEアカウントでクリエイター登録（無料）
2. マイページ →「新規登録」→「絵文字」を選択
3. タイトル・説明文（日本語/英語）・コピーライトなどを入力
4. 絵文字画像に `sosu_emoji_v3.zip` をアップロード（個数は40を選択）
5. タブ画像に `tab.png` をアップロード（ZIP内にも同梱済み）
6. 内容確認後「リクエスト」で審査申請 → 承認されたらリリース

## 加工内容メモ

- Gemini生成の透過PNG40枚を余白トリミング後、180×180キャンバスに最大サイズで配置（ガイドライン準拠）
- タブ画像は001（夢吉先生）の顔部分をクロップして96×74に配置
