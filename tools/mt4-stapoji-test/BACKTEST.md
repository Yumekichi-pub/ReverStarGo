# スタポジ バックテスト手順（StapojiEA.mq4）

ご著書 CHAPTER3 のルールをそのままEA化し、MT4のストラテジーテスターで
2022年以降などの過去相場を検証するためのものです。

---

## 1. 実装したルール

| 項目 | 既定値 | 出典 |
|---|---|---|
| 通貨ペア・方向 | USDJPY 買いのみ | CH3 冒頭 |
| 1本の量 | 1,000通貨（0.01ロット） | CH3 冒頭 |
| 積上幅（最初の1円） | 0.5円 | 「130.5円、131.0円と、積上幅0.5円」 |
| 積上幅（以降） | 0.2円 | 「131.2、131.4 … 積上幅0.2円」 |
| トレール開始 | 基準+1.0円 | 「1円高の131.0円が約定したら」 |
| トレール初期幅 | 0.5円 | 同上 |
| 幅の拡大 | 1本約定ごとに +0.1円 | 「トレール幅を0.1円ずつ広く変更」 |
| 拡大の停止 | 3.0円 | 「トレール幅が3円になった時にストップ」 |
| 先出し | 現在値の5円上まで | 「3円〜5円分ほどまとめて出す」 |

### 重要な単純化

全ポジションが「同じ現在値」を「同じトレール幅」で追うので、**逆指値はすべて同じ価格に揃います**。
ご著書の「3円反落したときにすべてのポジションが決済されてしまいます」と同じ挙動です。

そこでEAでは、個別のトレールではなく

```
決済ライン = （そのサイクルの最高値） − （トレール幅）
```

という1本の線として実装しています。挙動は同一で、計算はずっと軽くなります。

検算：積上幅0.2円につきトレール幅を0.1円広げるので、決済ラインは0.2円の上昇につき
0.1円しか上がりません。1,000ドル × 0.1円 = 100円。ご著書の
「0.2円上昇しても利益はたったの100円ずつしか増えなかった」と一致します。

### サイクル（今回の主題）

全決済されたら、**その価格から同じルールで新しいサイクルを開始**します。
1サイクル = 1回の試行として、開始/終了時刻・基準価格・最高値・決済価格・
上昇幅・ポジション数・確定損益をCSVに記録します。

知りたいのは合計利益だけではなく、**サイクルの分布**です。
「130円→160円で1回の大勝ちができたのか、それとも介入のたびに刈られて
小さな利益と仕切り直しを繰り返したのか」がこのCSVで見えます。

## 2. 設置とコンパイル

1. MT4 → **ファイル → データフォルダを開く** → `MQL4\Experts\` に `StapojiEA.mq4` を置く
   - ※ スクリプトではなく **Experts** フォルダです
2. MetaEditorで開いて **コンパイル**（`0 errors` を確認）
3. MT4のナビゲータ →「エキスパートアドバイザ」を右クリック →**更新**

---

## 3. ヒストリカルデータの準備

バックテストの質は**データの質で決まります**。ここを省くと結果は信用できません。

1. MT4 → **ツール → ヒストリーセンター**（F2）→ USDJPY → **1分足 (M1)**
2. 2022年1月まで遡ってデータがあるか確認

楽天MT4の標準データは期間が短いことが多いです。足りない場合:

- **無料の外部データ**（Dukascopy、HistData.com など）からUSDJPYのM1を入手し、
  ヒストリーセンターの「インポート」で読み込む
- より精度を上げるなら TickStory 等でティックデータを入れる（モデル品質99%）

M1データがあれば「始値のみ」より遥かにマシですが、トレール決済の
ヒット判定は足の中の値動きに依存するため、**ティックデータが理想**です。

## 4. テストの実行

**ツール → ストラテジーテスター**（`Ctrl+R`）

| 項目 | 設定 |
|---|---|
| エキスパートアドバイザ | StapojiEA |
| 通貨ペア | USDJPY |
| 期間 | M1（推奨） |
| モデル | 全ティック（最も正確） |
| 期間を指定 | ☑ 2022.01.01 〜 2026.08.31 |
| スプレッド | 現在値、または固定5（=0.5pips、実測値） |
| 初期証拠金 | 5000000 JPY、レバレッジ 1:25 |

「エキスパート設定」→「パラメーターの入力」で各ルールを変更できます。

実行後、**「操作履歴」タブ**にサイクルごとの1行ログが出ます:

```
--- cycle 3 CLOSED 2022.10.21 09:12  base=145.20 high=151.94 exit=148.94
    rise=6.74 yen  positions=34  trail=3.00  profit=41200 JPY  cum=58600
```

CSVは `<データフォルダ>\tester\files\Stapoji_USDJPY_trail3.0_xxxx.csv` に出ます。
Excelで開けば、サイクルごとの利益の分布がそのままグラフになります。

## 5. 最初にやるべき比較：トレール幅の最適化

「3円で刈られてしまう」というご懸念は、**そのまま最適化で検証できます**。

ストラテジーテスターの **「最適化」にチェック** → 「エキスパート設定」→
`TrailMaxYen` の行で:

| 開始 | ステップ | 停止 |
|---|---|---|
| 1.0 | 0.5 | 6.0 |

これで11通りが自動で回り、2022〜2026年において **トレール幅がいくつなら
最も利益が残ったか**が表になります。ご著書では「理想は5円くらい」と
書かれていますが、実データがそれを支持するかどうかが分かります。

同様に `StepYen`（積上幅）や `TrailWidenYen` も振れます。

## 6. 結果を読むときの注意点

**① 期間バイアス**

2022年以降のUSDJPYは 115円 → 160円 の歴史的上昇です。買いを積む手法なら
何をしても好成績になります。必ず以下も回して比較してください。

| 期間 | 相場 | 見るもの |
|---|---|---|
| 2022〜2026 | 大円安 | 本命 |
| 2015〜2021 | レンジ・下落 | 塩漬けの深さ |
| 2007〜2012 | 長期円高 | 最悪ケース |

**② スワップの扱い**

MT4のテスターは**現在のスワップ値を過去全期間に適用します**。
USDJPY買いは現在プラススワップですが、2022年前半の米金利はほぼゼロでした。
数百本を長期保有する手法ではスワップの影響が大きいため、
**この期間の損益は実際より良く出ます**。ここは差し引いて読んでください。

**③ 窓開け**

ご著書 CH3「窓開け」の指摘どおり、月曜早朝のギャップでトレール幅を超えて
決済されることがあります。M1データを使えばテスターもこれを再現します。
サイクルCSVで `exit` が `high − trail` より大きく下なら、それが窓開けです。

**④ 未決済のまま終わったサイクル**

テスト終了時にポジションを持ったままなら「OPEN」として記録します。
確定利益には含めず、含み損益として別に表示します。

## 7. 実運用との差（今日の実測より）

バックテストには出てこないが、実際の楽天MT4では効く制約:

| 項目 | 実測値 |
|---|---|
| 発注の最短間隔 | 約2秒（それより速いと err 141） |
| 1本あたり実効時間 | 約2.3秒 |
| 保留注文の証拠金消費 | ゼロ |
| StopLevel / FreezeLevel | 0（距離制限なし） |
| 100本連続発注 | エラーなし |

つまりバックテストで「5円分の先出し」が一瞬でできても、実際は
**20本の先出しに約46秒**かかります。急騰時に置き遅れる可能性があるので、
バックテストの結果より実運用のほうが不利になる方向です。
EAでは `PreOrderYen` を広めに取ることで緩和できます。
